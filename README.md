# 아난티 생성형 AI 실무 워크숍

아난티 임직원을 위한 생성형 AI 실무 교육용 강의 노트입니다. AI 도구 선택, 데이터 보안과 정제, 데이터 분석, 고객 VOC 기반 서비스 기획, HTML 대시보드 제작을 다룹니다.

## 접속 사이트

**[강의 노트 바로가기](https://datathinkinglab.github.io/ananti-ai-workshop/)**

사이트에서 슬라이드 목차, 프롬프트 복사, 샘플 데이터 다운로드 기능을 이용할 수 있습니다.

## 실습 자료

`sample_data` 폴더에 기초정보 DB, 오프라인 결제 DB, 고객 VOC 샘플이 포함되어 있습니다. 사이트 상단의 **샘플 데이터** 메뉴에서도 내려받을 수 있습니다.
